## 구성

매거진은 세 권으로 나뉘어 있어요.

- **Book I — AI × Series** · 주제별 27호 (249장). 철학·언어·예술 등 한 주제를 한 호에 깊게.

## 프로젝트 구조

```
{N}-cards-{slug}/            # Book I 카드 HTML 소스 (1080×1080)
{N}-outputs-{slug}/          # Book I 캡처 PNG
chronicle-{N}-cards-{slug}/  # Book II 카드 HTML
chronicle-{N}-outputs-{slug}/# Book II 캡처 PNG
atlas-{N}-cards-{slug}/      # Book III 카드 HTML
atlas-{N}-outputs-{slug}/    # Book III 캡처 PNG
images/                      # 공용 이미지 (Wikimedia Commons 출처)
style.css                    # Book I·II 공용 스타일
atlas.css                    # Book III 스타일
capture.py                   # Playwright 기반 PNG 캡처
fix_face_crop.py             # OpenCV 얼굴 중앙 자동 정렬
index.html                   # 포털 홈
series/{slug}.html           # Book I 시리즈 reader
chronicle/{slug}.html        # Book II 시리즈 reader
atlas/{slug}.html            # Book III 시리즈 reader
styles/site.css              # 포털 사이트 스타일
```

## 로컬 빌드

```bash
# 의존성 설치 (최초 1회)
pip3 install --break-system-packages playwright opencv-python
python3 -m playwright install chromium

# 전체 PNG 재생성
python3 capture.py --all

# 특정 시리즈만
python3 capture.py dream
python3 capture.py chronicle-cogwheel
python3 capture.py atlas-creativity

# 단일 슬라이드
python3 capture.py dream 02-dick

# 인물 사진 얼굴 중앙 자동 정렬
python3 fix_face_crop.py
```

## 디자인 시스템

세 권 모두 동일한 카드 그리드(1080×1080)와 타이포그래피를 공유하되, 색조로 구분돼요.

- **공통 폰트** · Pretendard 가변 + Playfair Display(serif accent) + JetBrains Mono
- **Book I** · 미디어 브랜드 톤 — `#E35205` 주황 / `#0f1e38` 네이비 / `#f4efe4` 베이지
- **Book II** · 시간축 톤 — 클래식 신문 그레이스케일 + 시대별 era 칩
- **Book III** · 박물관 청록 톤 — `#7a8a7a` 세이지 그린 / `#0e2a4a` 미드나잇 / `#c8a04a` 황동

전반적으로 Mirae Asset inspired 절제된 신뢰감 — 과장 없는 정보 밀도와 sans/serif 대비.
