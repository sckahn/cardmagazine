CASE · 2023

사내에 외부 AI를 풀어준 지 20일,
그 회사는 결국 사용을 막았습니다.

2023년 3월, 삼성전자 반도체 부문에서 일어난 일입니다. 외부 AI(Claude·Gemini·ChatGPT 등 서비스 전반)를 업무에 쓰자는 분위기가 잠깐 있었는데, 단 20일 만에 3건의 사내자료 유출이 확인되어 회사 차원에서 사용을 전면 차단했습니다.

유출된 3건 — 모두 "그냥 일하다가" 일어났습니다
SOURCE · TechCrunch / Cybernews 2023.05
CASE 1
소스코드 디버깅

버그를 풀려고 사내 소스코드를 그대로 외부 AI 채팅창에 붙여넣었습니다. → 외부 학습 데이터로 흘러갔습니다.

CASE 2
회의록 자동 정리

녹음 → 텍스트 변환한 사내 회의 내용을 외부 AI에 던져 회의록을 만들었습니다. → 회의 내용이 외부망으로.

CASE 3
테스트 시퀀스 최적화

반도체 수율 테스트 코드를 다듬어 달라고 요청했습니다. → 핵심 노하우가 외부 서버 로그에 남았습니다.
